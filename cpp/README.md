# Implementación en C++ — SGA-DO

Aquí va el código fuente en C++ del sistema (Módulo 6).
Esta versión en C++ aplica Programación Orientada a Objetos, gestión dinámica de memoria con punteros inteligentes (std::shared_ptr), 
polimorfismo puro, Pila (std::stack), Cola (std::queue) y manipulación de flujos de archivos (std::fstream / std::stringstream) 
para garantizar la persistencia en disco.

Pendiente de implementar:

- Persistencia mediante fstream (ifstream/ofstream)
- Gestión manual de memoria: new / delete para cada objeto dinámico (evitar memory leaks)
- Jerarquía de clases con herencia y funciones virtuales (polimorfismo real, no if/else por tipo)
- Pila y Cola implementadas manualmente o con std::stack / std::queue
